# Дворец молодежи

Откройте dist/index.html для локального просмотра. 

## Vercel

Для публикации через Vercel загрузите всё содержимое архива в корень репозитория, включая vercel.json, update-backgrounds.mjs и папку dist. Импортируйте репозиторий в Vercel. Оставьте Root Directory корнем репозитория. В Settings → Environments → Production → Branch Tracking выберите master. Последующие пуши в master будут обновлять основной сайт.

## GitHub Pages

1. Распакуйте архив и поместите его содержимое в корень репозитория. Включите скрытую папку .github с файлом workflows/pages.yml.
2. В Settings → Pages → Build and deployment → Source выберите GitHub Actions.
3. Сделайте push в master. Если файлы уже загружены, первый запуск можно выполнить через Actions → Publish to GitHub Pages → Run workflow, выбрав master.
4. После публикации откройте сайт через Settings → Pages → Visit site.

Каждый пуш в master обновляет список фонов и публикует содержимое dist. Основной адрес проекта обычно имеет вид https://ИМЯ.github.io/РЕПОЗИТОРИЙ/. Для размещения только на Vercel можно исключить .github/workflows/pages.yml.

## Альбомы и тексты

В dist/config.js у каждого альбома есть title (название переключателя) и embed (полный код iframe Яндекс Музыки между обратными кавычками или адрес из src). Первый альбом открывается автоматически. Вкладка «Счастье мое, я здесь и я жду тебя» использует массив songs. Скопируйте строку «Поезда», поменяйте song и iframe. Порядок строк определяет порядок песен. Плеер трека загружается при выборе песни.

soonUrl задаёт адрес «Скоро», about — текст раздела «О проекте», links — ссылки по группам. Фотография проекта лежит в dist/dm-photo.png.

## Фоны

Скопируйте изображения JPG, PNG, WebP или AVIF в dist/backgrounds. При деплое GitHub Pages и Vercel автоматически запускают node update-backgrounds.mjs. Для локального просмотра новых фонов запустите эту команду из корня проекта. Команда обновит перечень автоматически, в порядке имён файлов. Без Node.js можно добавить имена вручную в dist/backgrounds.js. Для управления порядком используйте префиксы 01, 02, 03. Интервал в секундах задаёт backgroundSeconds, по умолчанию 60.

## Плёночное зерно

В dist/config.js в разделе grain настройте size (размер зерна в пикселях), fps (число смен рисунка в секунду) и opacity (прозрачность слоя от 0 до 1, при 0 зерно исчезает). При включённом системном уменьшении движения зерно остаётся неподвижным.

## Мой компьютер

В dist/config.js у альбома есть background для постоянного фона, tracks для песен и questions для карточек. Поле cards у трека задаёт изображения в порядке показа. У каждого вопроса front и back задают лицевую и обратную стороны, question и answer содержат текст для экранных дикторов. Пути указываются относительно dist.

## Статистика посещений

Создайте счётчик Яндекс Метрики для dmpostpunk.github.io и впишите его числовой номер в `metrikaId` в `dist/config.js`. После публикации в GitHub Pages визиты и посетители появятся в кабинете владельца счётчика. Значение `null` отключает сбор. Локальные открытия исключены.

Для отчётов по действиям создайте цели типа «JavaScript-событие» с идентификаторами `album_select` (выбор раздела), `player_select` (выбор кнопки в разделе), `quiz_open` (открытие квиза), `quote_image` (открытие или скачивание картинки) и `external_link` (переход по внешней ссылке). Выбор плеера не подтверждает прослушивание. Текст введённого вопроса в параметры событий не передаётся.
